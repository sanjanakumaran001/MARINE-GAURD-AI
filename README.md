# Marine Guard – AI-Enabled Smart Rescue Jacket Website

The **Marine Guard website** is a responsive web-based monitoring dashboard designed to improve the safety of fishermen and marine workers. It provides a centralized platform to monitor wearable jacket sensor data, view GPS-based location information, and manage emergency alerts.

The dashboard is designed with a simple and user-friendly interface that allows users to understand the wearer's status through sensor readings, location details, and alert notifications. It includes dedicated sections for temperature and humidity monitoring, movement detection, GPS tracking, emergency alerts, device status, and monitoring reports.

The frontend is developed using **HTML, CSS, and JavaScript**, while the backend uses **Node.js and Express.js** to manage data and application services. A **Python Flask service** is planned for future integration of machine-learning-based analysis. The system is designed to support communication with the ESP32-based smart jacket when hardware integration is completed.

The website also supports a clearly labelled demonstration mode with simulated sensor readings for testing the dashboard before connecting the actual hardware.

**Overall, the Marine Guard website acts as a digital monitoring platform that supports the smart rescue jacket by presenting sensor information, location details, and emergency notifications in one place.
